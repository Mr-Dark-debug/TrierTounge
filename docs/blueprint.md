# **App Name**: TrierTongue

## Core Features:

- Reciprocal Language Matcher with AI Tool: A smart algorithm tool that ensures students have reciprocal needs and uses reasoning to provide an AI-generated compatibility summary based on shared academic and social goals.
- Progressive Trier Profile Builder: A 5-step onboarding flow specifically designed for University of Trier students to capture linguistic skills, major details, and real-time availability with persistence-save features.
- Integrated Student Auth & Database: Secure sign-up and authentication flow that stores profiles in a persistent database, allowing users to log out and securely return to their dashboard.
- Match Quality & Breakdown Dashboard: An interactive dashboard featuring a profile completion meter and an expandable breakdown tool explaining the logical weights behind each match score.
- Availability Heatmap Synchronizer: A visual 7x3 grid that overlays your schedule with potential partners to highlight overlapping free slots on the Trier campus.
- Privacy-Locked Contact Reveals: Granular visibility controls for contact handles like Telegram and Instagram, featuring a smooth unlock animation once a match is mutually accepted.
- Universal Discovery & Campus Filters: Searchable student directory with filters for Trier-specific majors, study years, and meeting formats with 'New' badges for recent profiles.

## Style Guidelines:

- Primary color: Vibrant Lime (#BEF264) for buttons and active states. Secondary color: Soft Pink (#FF80FF) for highlights and creative text decorations.
- Background: Creamy White (#F9FAF5) with a subtle graph-paper grid pattern. Accents: Deep Pitch Black (#000000) for sharp borders and text.
- Headlines use 'Fraunces' (Serif) for a sophisticated, editorial look; body text uses 'Manrope' (Sans-serif) for high legibility in dense profiles.
- Neo-brutalist card design with thick 2px black borders and sharp corners. Mobile-first bottom navigation for student on-the-go access.
- Playful, high-contrast monochrome line icons and small flag indicators for language identification.
- Snappy, high-energy transitions between dashboard tabs and scroll-triggered fade-ins for the landing page 'how-it-works' section.
